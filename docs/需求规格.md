# 待办 · 提醒 桌面应用 — 需求规格 v1.0

> 状态：已按本文实现、打包并安装（2026-10-30）。使用与卸载见仓库根目录 README。

## 1. 定位

单机、单用户、Windows 桌面端待办 + 定时提醒工具。核心闭环：**建任务（必填截止时间）→ 可选设提醒 → 到点弹窗/系统通知 → 勾完成**。

- 不联网、不登录、不同步。
- 常驻系统托盘，开机自启（静默进托盘）。
- **全程无提示音**。

## 2. 技术方案

| 项 | 选择 |
| --- | --- |
| 运行时 | Electron（主进程管托盘/通知/自启/存储，渲染进程管界面） |
| 界面 | 原生 HTML/CSS/JS，不引框架，保证启动快、体积可控 |
| 打包 | electron-builder，产出安装版（桌面 + 开始菜单快捷方式，可固定到任务栏） |
| 数据 | `%APPDATA%\WorkPlan\data.json`，原子写入 + 每日备份保留 7 份 |
| 环境 | 本机 Node v25 / npm 11 / 网络可达 npmjs 与 npmmirror，满足构建条件 |

> 本机受限沙箱无法执行命令（进程 0xC0000142），所有构建命令需在「完全访问」下执行，会逐次请求你批准。

## 3. 界面结构

### 3.1 主窗口

- 默认 1180 × 780，最小 940 × 620，居中启动，单实例（重复启动唤起已有窗口）。
- 三块：左侧边栏（240px）/ 主列表区 / 顶部工具栏。
- 顶部工具栏：当前视图名、搜索框、新建按钮；其下常驻一行汇总统计（见 3.8）。

### 3.2 左侧边栏（自上而下）

1. **一级入口（四个，互斥）**
   - `按时间`：主区一条时间轴，未删除的全部任务（含已完成）按截止时间升序；不做任何日期分桶。
   - `按完成度`：进页后主区顶部出现 `未完成 / 部分完成 / 已完成` 三个标签（带数量，默认停在「未完成」），点标签切换该组列表。
   - `逾期任务`：未完成或部分完成，且截止时间严格早于当前时间；按截止时间升序。
   - `重要任务`：打过星标的全部任务（含已完成）；排序同「按时间」，时间优先、同一时间再看完成度。
2. **分类过滤**：26 个分类按 5 组折叠展示（学业 / 事务 / 生活 / 竞赛公益 / 其他）。
   - 点击某个分类 = 只显示含该分类的任务（一条任务最多挂 3 个分类，命中其中任意一个就列出）；再点取消。
   - 过滤只决定「进不进列表」，任务卡片上挂的全部分类色块照常显示，不隐藏、不合并。
   - 与当前入口是「且」关系；顶部显示可一键清除的过滤胶囊。

**入口口径**

| 入口 | 含义 |
| --- | --- |
| 按时间 | 未删除的全部任务（含已完成），按截止时间升序 |
| 按完成度 | 顶部标签切换：未完成 / 部分完成 / 已完成（按第 4 节推导） |
| 逾期任务 | 未完成或部分完成，且 截止时间 **严格早于** 当前时间（正好相等不算逾期） |
| 重要任务 | `starred === true` 的全部任务，排序同「按时间」 |

### 3.3 任务列表

- **纯按截止时间升序**，不做任何日期分组。
- 截止时间完全相同的任务，按 `未完成 → 部分完成 → 已完成` 排；仍相同则按创建时间。
- 逾期任务自然排在最前，时间文字标红并显示「逾期 2 小时」。
- 已完成任务**原位保留**，标题划线、整体降透明度，不隐藏、不沉底。
- 单列纵向排列，一行一条，不排网格。
- 星标只是标记，**不改变「按时间」里的位置**；只有「重要任务」入口会单独聚合。
- 行内元素：星标 · 勾选框 · 标题 · 1–3 个分类色块（全部照常显示）· 截止时间 · 提醒图标（有则显示时间）· 子任务进度 `2/3` · 备注展开箭头。
- 空状态：插画位 + 「暂无任务」+ 新建按钮。

### 3.4 快速添加

- 顶部常驻一行：`[标题输入框] [截止时间 · 未设置] [分类] [提醒] [+]`。
- 截止时间**不设任何默认值**，初始显示「未设置」；没有截止时间的任务一律不允许创建。
- 分类**不预填**；没选分类时自动归入「其他/杂项」，并提示一次；选了就只按选的来，不会再附加「其他/杂项」。
- 回车时若截止时间为空：**不创建**，日期字段标红并自动展开日期选择器（定位到今天），提示「请先设置截止时间」。
- 创建成功后清空截止、提醒和分类的选择，光标回到标题输入框，连续录入时每条都从干净状态开始。
- 截止时间填好后回车即入库，光标回到标题输入框，方便连续录入。
- 分类必选 1–3 个；提醒可空。

### 3.5 行内编辑（实时保存，无确认按钮）

- 点标题 → 就地变输入框，失焦/回车保存。
- 点截止时间 → 弹日期时间选择器（可快捷选 今天/明天/下周，可精确到分）；已有任务只能改成另一个时间，**不允许清空**。
- 点分类 → 弹分类选择浮层，最多 3 个，超出时提示并禁用第 4 个。
- 点提醒 → 设置/修改/清除提醒时间；不能设成空字符串以外的非法值。
- 展开任务 → 备注多行文本 + 子任务清单（勾选、添加、删除、重命名）。
- 点星标 → 切换「重要」；备注里的 `http(s)` 链接自动识别为可点击，点击用系统浏览器打开。

### 3.6 搜索

- 顶部搜索框实时过滤，匹配：标题、备注、子任务标题。
- 结果命中文字高亮；`Esc` 清空并退出搜索。
- 搜索时跨当前视图，命中项标注所属视图。

### 3.7 删除

- 入口：行尾「⋯」菜单 → 删除。
- 弹自定义确认框：「删除后无法恢复」+ 取消 / 删除。
- 确认后彻底删除；若该任务有提醒弹窗，弹窗立即关闭。

### 3.8 顶部汇总条

- 每个页面顶部常驻一行，左起：`共 N 条` · `未完成 X` · `部分完成 Y` · `已完成 Z` · `逾期 W`。
- 「重要任务」页额外显示 `重要 K`；「按完成度」页右侧显示进度条 `Z/N`。
- 数字随增删改勾选实时更新；纯展示，不可点击。

## 4. 数据模型

```jsonc
{
  "version": 1,
  "settings": { "theme": "dark", "autoLaunch": true, "lastCategoryIds": ["misc"] },
  "categories": [
    { "id": "study", "name": "学习", "group": "学业", "color": "#6B8CFF" }
  ],
  "tasks": [
    {
      "id": "t_20261030_0001",
      "title": "交实验报告",
      "note": "含数据图和结论",
      "starred": false,
      "dueAt": "2026-10-31T18:00:00",
      "remindAt": "2026-10-31T17:00:00",
      "remindFiredAt": null,
      "categoryIds": ["lab", "report"],
      "subtasks": [
        { "id": "s_01", "title": "整理数据", "done": true, "doneAt": "2026-10-30T10:00:00" },
        { "id": "s_02", "title": "写结论", "done": false, "doneAt": null }
      ],
      "done": false,
      "doneAt": null,
      "createdAt": "2026-10-30T09:00:00",
      "updatedAt": "2026-10-30T10:00:00"
    }
  ]
}
```

**状态推导（不落库，实时算）**

- `done === true` → 已完成
- `done === false` 且 存在子任务已完成 → 部分完成
- 其余 → 未完成

主任务勾完成即整条进已完成，不要求子任务全部完成；无子任务的任务只在未完成/已完成之间切换。勾选后列表实时刷新，不需要手动刷新。

**分类改名级联**：任务只存分类 `id`，界面名来自 `categories[].name`。把「踢球」改成「足球」只改一处显示名，全部历史任务自动跟随。分类由开发者维护，界面不提供增删改入口。

## 6. 提醒系统

### 6.1 触发

- 主进程每 20 秒扫描一次「`remindAt <= now` 且 `remindFiredAt` 为空 且 未完成 且 未删除」的任务。
- 命中后：① Windows 系统通知（`silent: true`）② 右下角置顶卡片。
- 电脑睡眠唤醒、系统时间变更后立即重扫。

### 6.2 弹窗规格

- 独立无边框窗口，屏幕右下角，距边 12px，宽 360，高自适应（上限 420）。
- 始终置顶、不抢当前输入焦点、不显示在任务栏。
- **不自动消失**，必须手动处理；不限张数，全部弹出，自下而上堆叠。
- 堆叠总高超过屏幕可用高度 70% 时，卡片区内部滚动（最新一张始终贴着右下角），不会溢出到屏幕外。
- 内容：分类色块 + 标题 + 「截止 今天 18:00」+ 备注首行（有则显示）。
- 按钮：`稍后提醒` `知道了`。
  - 稍后：5 分钟 / 10 分钟 / 30 分钟 / 自定义分钟数（1–1440）。
  - 知道了：标记 `remindFiredAt`，关闭卡片。
- 无「完成」按钮（按你的要求，完成回主窗口勾）。

### 6.3 错过补弹

- 启动时、以及从托盘恢复时，扫描所有已过点但未提醒且未完成的任务。
- 合并为一张「有 N 条错过的提醒」卡片，逐条列出标题 + 原本提醒时间，可「全部知道了」或单独处理。
- 补弹不写 `remindFiredAt` 之外的副作用，不会重复轰炸。

### 6.4 托盘与自启

- 关闭窗口（× / Alt+F4）= 隐藏到托盘，进程常驻，提醒照常。
- 托盘图标：有逾期或待处理提醒时带红点。
- 托盘菜单：打开主窗口 · 逾期任务 · 开机自启（勾选）· 退出。
- 真退出只能走托盘菜单「退出」；退出前把待触发提醒落盘，下次启动补弹。
- 开机自启写注册表 `Run`，启动参数 `--hidden`，静默进托盘不弹主窗口。

## 8. 边界与异常

| 场景 | 处理 |
| --- | --- |
| 提醒时间填成过去 | 保存时提示「该时间已过，将立即提醒」，确认后立即触发 |
| 提醒时间晚于截止时间 | 允许，不做校验 |
| 修改截止时间 | 不联动修改提醒时间，除非用户主动改 |
| 修改提醒时间 | 重置 `remindFiredAt`，重新计时 |
| 删除任务 | 关闭其弹窗，取消待触发提醒 |
| 数据文件损坏 | 从最近备份恢复并提示；备份全坏则备份原文件后新建空库 |
| 多开 | 单实例，第二次启动唤起已有窗口 |
| 提醒窗口开启时退出 | 先落盘再退出，保证不漏 |

## 9. 我替你定的默认值（不认同就改）

1. 窗口 1180×780，最小 940×620。
2. 截止时间不设默认值，必须由用户显式选好才能创建任务。
3. 一条任务只支持 1 个提醒（不是多个）。
4. 提醒弹窗不限张数，超出屏高时卡片区内部滚动。
5. 一条任务最多 3 个分类，最少 1 个。
6. 逾期判定为「截止时间严格早于现在」，正好等于当前时刻不算逾期。
7. 分类过滤一次只选一个。
8. 星标不影响「按时间」的顺序，只多一个聚合入口。
9. 不做优先级、重复任务、附件、导出。
